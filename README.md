# ASL Dataset for Sign Language Recognition

This repository contains a custom American Sign Language (ASL) dataset created for my final year project in computer science.

## Dataset Details

- **Image Size**: 640x640 pixels  
- **Images per Sign**: 150  
- **Total Signs**: 100  
- **Total Images**: 15,000  
- **Format**: JPG 
- **Use Case**: Training machine learning models for ASL recognition
